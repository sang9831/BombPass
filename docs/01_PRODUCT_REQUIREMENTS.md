# 제품 요구사항 명세서 (PRD)
## 1. 사용자와 목표
대상: 짧은 세션의 경쟁 게임을 즐기는 브라우저 사용자. 목표: 2~30인 실시간 폭탄 돌리기와 정확한 단일 소유권 보장.

## 2. 사용자 스토리
- US-01 회원은 로컬·Google·Kakao로 로그인한 뒤 닉네임을 설정하고 방을 만들거나 코드로 참여한다.
- US-02 방장은 최소 2명일 때 게임을 시작한다.
- US-03 플레이어는 자신의 폭탄 보유 여부와 타이머를 실시간으로 본다.
- US-04 폭탄 소유자는 버튼을 눌러 다른 생존자에게 전달한다.
- US-05 참가자는 폭발, 탈락, 남은 인원, 최종 승자를 즉시 확인한다.
- US-06 일시적으로 끊긴 참가자는 재연결해 현재 상태를 복원한다.
- US-07 사용자는 종료 후 개인 전적을 조회한다(2차).

## 3. 규칙
- 방 상태: WAITING → COUNTDOWN → RUNNING → FINISHED / CANCELLED.
- 시작 시 생존자 중 한 명에게 폭탄 배정. 폭발 시 현재 소유자 탈락.
- 폭탄은 서버가 생성한 폭발 시각에 폭발하며 클라이언트 타이머는 표시 전용.
- 폭발 시각 이후 도착한 전달은 거절. 폭발과 전달은 Redis 원자 연산으로 순서 결정.
- 전달 성공 조건: RUNNING, 현재 소유자 일치, 대상 생존, 자신 이외, 쿨타임 경과, 폭발 전, 요청 ID 중복 아님.
- 전달 대상은 직접 선택을 우선 검토하며 무작위 모드도 후보로 둔다. 유사 게임 플레이 테스트 후 확정한다.
- 폭발 후 생존자 2명 이상이면 다음 폭탄 라운드, 1명이면 종료.
- 네트워크 끊김 시 플레이어는 게임 상태에 남고 폭탄은 계속 진행. 재접속 유예(후보 10초), 자동 전달 및 탈락 정책은 유사 게임 조사와 악용 테스트 후 확정.
- 공정성 기준: 서버 수신 후 Redis 판정 순서. 클라이언트 시계는 판정에 사용하지 않음.

## 4. 기능 요구사항
| ID | 기능 | 우선순위 | 수용 기준 |
|---|---|---|---|
| FR-01 | 로컬·Google·Kakao 로그인 | P0 | 로컬 회원가입/로그인, Google/Kakao OAuth2, 계정 연결 및 JWT 발급 |
| FR-02 | 방 생성·참가·퇴장 | P0 | 정원 초과 및 시작된 방 입장 거절 |
| FR-03 | 방장 게임 시작 | P0 | 최소 2명, 중복 시작 불가 |
| FR-04 | 실시간 게임 상태 | P0 | 전체 상태 스냅샷 및 버전 제공 |
| FR-05 | 폭탄 전달 | P0 | 한 시점에 단일 소유자, 중복 클릭 멱등 |
| FR-06 | 서버 폭발 판정 | P0 | 만료 시각 이후 전달 불가, 정확히 1명 탈락 |
| FR-07 | 최종 승자 결정 | P0 | 생존자 1명일 때 한 번만 종료 |
| FR-08 | 재연결 | P0 | 최신 스냅샷과 이벤트 버전 복원 |
| FR-09 | 게임 결과 영속화 | P1 | 결과 DB 중복 저장 방지 |
| FR-10 | 보상/전적 | P1 | 중복 보상 방지 및 이력 조회 |
| FR-11 | 이벤트 통계 | P2 | Kafka 기반 전달·폭발 이벤트 집계 |
| FR-12 | 시즌 랭킹 | P2 | Supabase PostgreSQL 정산과 Redis 캐시 일치 |

## 5. 비기능 요구사항(초기 목표, 측정 전)
- NFR-01 폭탄 소유자 중복 0건(동시성 테스트 전 케이스).
- NFR-02 동일 요청 ID 중복 처리 0건.
- NFR-03 정상 부하에서 전달 명령 p95 200ms 이내(서버 측 목표, 환경별 재조정).
- NFR-04 100 동시 WebSocket 연결부터 점진적으로 300/500 검증. 실제 무료 VM 성능에 따라 조정.
- NFR-05 서버 인스턴스 하나 재시작 후 재연결 및 게임 상태 복원.
- NFR-06 배포 시 HTTP 5xx 급증 방지, WebSocket은 재연결 허용.
- NFR-07 관측성: 오류율, p95, WS 연결 수, RabbitMQ 적체, Kafka lag.

## 6. 제외 범위
실제 현금 거래, 도박, 모바일 네이티브 앱, 정교한 물리 엔진, 실시간 음성 채팅, 글로벌 리전 매칭.

## 7. 화면 목록
로그인/회원가입/소셜 로그인 → 프로필 설정 → 방 목록/코드 참가 → 대기실 → 게임 화면(폭탄/전달/생존자/타이머) → 결과 화면 → 전적(2차). UI는 키보드·모바일 클릭을 지원.
